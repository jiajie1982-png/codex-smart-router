# Directory submission draft

This repository is a public community marketplace. It is not an approved OpenAI directory listing. The public directory requires a publisher account with Apps Management Write access and verified individual/business identity, submission review, and a separate publish step after approval.

Use `draft.json` as editable submission information, `plugins/codex-smart-router/assets/logo.png` as logo, and the self-contained skill ZIP from `tools/build_release.py`. The skill references only files included in its folder. Windows-only launch is a compatibility limitation to disclose to reviewers; acceptance is not guaranteed. Test in the actual target review environment before submitting.

The publisher must supply/confirm region availability, identity details and required attestations in the portal. No identity verification, legal attestation, submission or approval is implied by this draft.

Official workflow: https://developers.openai.com/plugins/deploy/submission
